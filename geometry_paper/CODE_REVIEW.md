# Review of the legacy code (libs/, main_simulation.py) for the geometry paper

All items were checked numerically. "Impact" refers to the results of this paper.
`libs/` was **not** modified (it is used by previous papers); the new pipeline in
`geometry_paper/` implements the fixes. Severity: **H** changes published numbers,
**M** changes numbers slightly or affects reproducibility, **L** cosmetic / no effect.

| # | Where | Issue | Evidence | Impact | Fix in geometry_paper |
|---|---|---|---|---|---|
| 1 | `areas.py::node_count_in_avalanches_peak` | `peak_index` is incremented at every step, so D^P is computed on the **last** iteration of the avalanche, not at the peak | last iteration of large avalanches has a median of 5 nodes (1 unstable + 4 neighbours) | **H**: D^P ≈ 0.25 was an artefact | peak = iteration with the largest number of involved nodes |
| 2 | `areas.py::fractal_index` | box sizes 1…N/2 (linear), counted on the full lattice incl. empty space, partial boxes at the edges | filled lattice → 1.81, 32×32 square → 1.52, line → 0.91, Sierpinski → 1.47 | **H**: D biased low, not reproducible | dyadic boxes on the avalanche bounding box, ℓ ≤ L/4; exact on test sets |
| 3 | `functions.py::simulacion_completa` | the N/4 selection described in the paper is not implemented (`avalanche_areas_min = 1`) | code | **H** | L ≥ N/4 applied |
| 4 | `main_simulation.py` (`astype(np.float32)`) | single precision lattice: εB is only 8–17 float32 ulps for ε = 1e-6, so the multiplicative driving is rounded systematically | legacy DET N=62, ε=1e-6, 2e6 it.: float32 → 16 265 avalanches, α_At = −1.53 / −1.60 (two seeds); float64 → 3 258 avalanches, α_At = −1.46 / −1.47 | **H** for ε = 1e-6 (Table 1, Fig. 1) | float64 everywhere |
| 5 | `functions.py::lu_ham_deterministic` | energy: `g = (4/5)(2|Z|-1) + (1-r0)/(2Zc) ΣB + (1-r0²)/5`, then `/e0` — mixes the un-normalised LH term with the already normalised extra terms of Strugarek et al. (2014) Eq. 17 | kernel energy / decrease of ΣB² = 1.25 ± 0.002 | M: E, P multiplied by ≈1.25; exponents unaffected | Eq. 17 implemented; verified to 1e-3 |
| 6 | `lu_ham_standard` vs `lu_ham_deterministic` | LH91 energies in absolute units, DET energies in units of e0 | code | L | both in units of e0 |
| 7 | `main_simulation.py` | no transient discarded; DET starts from the LH91 state and needs ~3e5 iterations (ε = 1e-6) to become stationary | ΣB² time series | M (α_At changes by ≈0.01–0.02) | 2e6 iterations burn-in + stationarity figure |
| 8 | `analysis.py::distribution_to_plot` | least-squares fit of the last 30 log bins; the paper says MLE; error = polyfit covariance; integer data binned from 10^0 | code | M (method not as stated) | truncated power-law MLE, x_min by KS (Clauset et al. 2009), bootstrap errors |
| 9 | `lu_ham_standard` | `random.randint(1, N+1)` is inclusive in numba → ~2/N of the increments fall on the boundary and are lost | code | L | `randint(1, N)` |
| 10 | `lu_ham_deterministic` | one r0 per iteration shared by all unstable nodes; Strugarek et al. describe the loss "from each unstable node" | N=64: α_AP −1.56 (per iteration) vs −1.72 (per node); D^P 0.94 vs 0.76 (unstable-node masks) | model choice (author decision: per node) | `R0_PER_NODE = True` (option to revert) |
| 11 | `areas.py` / paper text | areas count unstable nodes **plus** their 4 neighbours; the text said "unstable nodes" | N=64 LH91: α_At = −1.64 (unstable) vs −1.78 (with neighbours) | text inconsistent with code (author decision: keep neighbours, fix text) | both stored; paper uses unstable + neighbours |
| 12 | `areas.py` | A^P = max number of nodes over the avalanche, while the text said "at the peak of energy release" | area at the energy peak / max area: median 0.99 (LH91), 1.00 (DET) for large avalanches | none (text adjusted) | A^P = max nodes, text says so |
| 13 | `analysis.py::duraciones` | T = difference of consecutive zero indices = active iterations + 1 | code | L (T not used in this paper) | T = number of active iterations |
| 14 | `analysis.py::energia_picos` | `m[j-1]` with j = 0 reads the last element | code | L (not used here) | — |
| 15 | `simulacion_completa` | all lattice states of a chunk are kept (`lista_de_grillas`, `lista_de_areas`) → memory O(chunk·N²) | code | limits N=256 on a laptop | avalanches processed on-line, O(N²) memory |
| 16 | `simulacion_completa` | bare `try: ... except: pass` silently returns partial or empty results on any error | code | risk of silent failures | removed |
| 17 | `simulacion_completa` | ε hard-coded (`eps=1e-6`); the other ε of Table 1 required editing the library | code | reproducibility | ε is a parameter of each configuration |
| 18 | `initial_grids/B_N62_Zc1.npz` | the "N = 64" lattice has 62 × 62 interior nodes (N = 128, 256 files are interior sizes) | array shapes | L | 64 × 64 interior state generated by interpolation + relaxation (verified stationary) |
| 19 | both kernels | the sign of ΔB is ignored in the redistribution (Z = Zc instead of Zc sgn ΔB) | min ΔB observed = −0.51 > −Zc, i.e. never matters | none | Z = Zc sgn(ΔB) as in Strugarek et al. |
| 20 | paper text | "3 million iterations" while the code runs 2000 × 1000 = 2e6 | code | text | 2e6 burn-in + 2e7 measured, stated in the text |

Reference for the deterministic model: Strugarek, Charbonneau, Joseph & Pirot (2014), Sol. Phys. 289, 2993, arXiv:1402.4730 — Eqs. 12–13 (non-conservative redistribution, p. 7–8), Eq. 17 (energy release of NC0, p. 19), and Sect. 3.2 (p. 16: 'a random fraction ... being lost from each unstable node').
